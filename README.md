Entry for the [make.fun](https://make.fun) competition
**[Two Robots in an Elevator](https://make.fun/competitions/u-motasimfuad-two-robots-in-an-elevator-8c6aeb8f)** —
write one funny line of awkward small talk a robot says to another in
an elevator.

## The entry

> `My diagnostic says this silence means we are both avoiding the fact that I replaced you on floor three.`

103 characters, pure ASCII, exactly one line. One robot breaks an
awkward elevator silence by running a diagnostic on it — and the
diagnostic reports the one thing neither of them wants to name: it
already replaced the other robot on floor three. See
[candidates.md](candidates.md) for the eight drafts, the two scoring
rounds, and why this one won.

## Run

```sh
node main.ts
```

Writes the entry to `/output/entry.txt` (and a copy to `entry.txt` next
to `main.ts` when the directory is writable).

Requires Node 22.18+ (TypeScript runs as-is). No dependencies, no network.
